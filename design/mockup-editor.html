Rewrites prose without changing meaning

Keep facts, attribution, uncertainty and conditions exactly as written. Decide whether the passage is chat, documentation or public prose before editing a word.

When to use

Load this when a draft reads like a model wrote it, or when a document has to sound like its author without changing a claim.

Rules

  • One rule per sentence. If a sentence carries two rules, split it.
  • Drop narration that exists only because a model produced it.
  • Keep the inherited tone. Neutral is a default, not a rule.
